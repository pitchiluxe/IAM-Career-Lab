# MASTER ROADMAP

| Year | Role target | Main outcome |
|---|---|---|
| 1 | Help Desk / IT Support | Become reliable at Windows, networking, AD and security troubleshooting |
| 2 | IAM Analyst | Operate identity lifecycle, SSO, MFA, RBAC and access workflows |
| 3 | IAM Engineer | Build automation, integrations, APIs, IGA/PAM workflows |
| 4 | IAM Architect | Design enterprise IAM, Zero Trust, governance and executive strategy |

## Career progression

### Year 1
IT foundations -> Windows -> networking -> Active Directory -> GPO -> PowerShell -> security -> ticket escalation -> capstone.

### Year 2
Identity concepts -> lifecycle -> directories -> SSO -> MFA -> RBAC -> federation -> access reviews -> IAM incident handling -> analyst capstone.

### Year 3
Engineering standards -> automation -> APIs -> directory integrations -> IGA -> PAM -> secrets -> event-driven workflows -> incident response -> engineer capstone.

### Year 4
Architecture principles -> Zero Trust -> IAM governance -> IGA/PAM strategy -> risk -> resilience -> operating model -> leadership -> executive architecture defense.

## Portfolio rule

Every year must produce:
1. architecture diagram,
2. implementation notes,
3. screenshots/evidence,
4. troubleshooting record,
5. security considerations,
6. lessons learned,
7. README suitable for GitHub,
8. sanitized scripts/configuration.
