# YEAR 2 BUILD PROMPT — IAM ANALYST

Extend the existing OMARI Technologies environment. Do not rebuild Year 1.

## Objectives
- identity and access fundamentals
- joiner/mover/leaver
- RBAC
- SSO
- federation
- MFA
- access requests
- access reviews
- identity investigations
- Entra/Okta-style workflows

## Authorized cloud/service rule

Use only an authorized tenant, developer environment, trial, or local equivalent. If a commercial platform is unavailable, implement the concept with the local AD environment and a legitimate open-source/test application.

## Required artifacts
- identity lifecycle workflow
- access request form
- role matrix
- SSO architecture diagram
- MFA policy
- access review report
- IAM ticket queue
- analyst capstone

## Analyst mindset
Treat identities as business objects with owners, lifecycle states, entitlements, evidence, and auditability.
