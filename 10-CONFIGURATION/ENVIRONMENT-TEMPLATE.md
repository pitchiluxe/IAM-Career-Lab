# ENVIRONMENT TEMPLATE

Use a local `.env` file only where necessary and keep it out of Git.

Example variables:
- LAB_DOMAIN
- LAB_DNS_SERVER
- OLLAMA_BASE_URL
- OLLAMA_MODEL
- AUTHORIZED_IAM_TENANT_ID (only if legitimately needed)
- AUTHORIZED_IAM_CLIENT_ID (only if legitimately needed)

Never place secret values in this template or in documentation.
