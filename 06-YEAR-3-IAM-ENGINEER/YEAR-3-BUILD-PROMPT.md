## Engineering standards

All automation must:
- use least privilege
- validate inputs
- log useful events without secrets
- support dry-run where practical
- fail safely
- be testable
- have rollback guidance
- avoid hard-coded credentials
- document API permissions

## Commercial products

Okta, SailPoint, CyberArk and similar products must only be used through authorized environments. Build concept-equivalent local labs when access is unavailable.
