# IAM Incident Response

## Goal
Investigate suspicious identity events and contain authorized accounts safely.

## Engineering workflow
1. Define requirements.
2. Define identity/data model.
3. Define permissions.
4. Implement.
5. Test normal and failure cases.
6. Validate security.
7. Document.

## Required evidence
Architecture, source code, test results, logs, threat considerations and rollback procedure.

## Instructor
Ollama acts as an engineering reviewer and asks why a design is safe, scalable and maintainable.
