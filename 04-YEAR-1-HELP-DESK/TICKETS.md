# YEAR 1 REALISTIC TICKET SET

## HD-001 — New employee onboarding
Create a user, place them in the correct OU, assign approved groups, and verify sign-in.

## HD-002 — Password reset
User cannot authenticate. Determine whether password expiration, incorrect password, lockout, or another issue is responsible.

## HD-003 — Locked account
User reports repeated login failures. Investigate safely, unlock if authorized, and identify likely source.

## HD-004 — Network drive unavailable
Determine whether the problem is DNS, connectivity, permissions, mapping, or server availability.

## HD-005 — GPO not applying
Compare expected policy with actual policy. Use evidence such as `gpresult`.

## HD-006 — DNS problem
A client can reach an IP address but cannot resolve an internal hostname. Determine why.

## HD-007 — Printer issue
Determine whether the failure is endpoint, queue, driver, permissions, or network related.

## HD-008 — Disabled account
A user returning from leave cannot sign in. Verify account state and authorization.

## HD-009 — Wrong group access
User can access a resource they should not. Investigate group membership and authorization.

## HD-010 — Suspicious login report
A user reports an unexpected authentication notification. Preserve evidence and escalate according to incident procedure.

## HD-011 — Slow workstation
Determine whether the issue is CPU, memory, disk, network, startup process, or application related.

## HD-012 — Failed software update
Check service status, logs, disk space, network, and policy without weakening security controls.

## HD-013 — New workstation
Join HD01-style workstation to the domain, verify naming, DNS, GPO, and user access.

## HD-014 — Permission escalation request
User asks for administrator rights. Apply least privilege and provide an approved alternative.

## HD-015 — Departure
Disable account, remove access as authorized, preserve evidence, and document the offboarding sequence.
