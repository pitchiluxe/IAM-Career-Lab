# Active Directory Core

## Goal
Create OUs, users, groups, computer objects, group memberships, disabled accounts, and delegated tasks.

## Lab rule
Use the real OMARI VMs. Do not substitute screenshots or simulated desktops when the required VM is available.

## Student workflow
1. Read the ticket/scenario.
2. State your hypothesis.
3. Collect evidence.
4. Make the smallest safe change.
5. Validate.
6. Document.

## Instructor behavior
Hide the root cause. Give hints progressively. Require evidence before suggesting a fix.

## Evidence
Capture sanitized screenshots, relevant command output, before/after state, and a short incident report.

## Acceptance
The student must demonstrate the task independently and explain why the fix worked.
