# SCRIPTS

The coding agent should place validated automation here.

Recommended categories:
- host readiness
- Hyper-V
- AD provisioning
- GPO validation
- ticket generation
- evidence collection
- IAM lifecycle automation
- API clients
- reports

Scripts must include:
- purpose
- prerequisites
- parameters
- permissions
- safe-use warning
- validation
- rollback where applicable

Never embed credentials.
